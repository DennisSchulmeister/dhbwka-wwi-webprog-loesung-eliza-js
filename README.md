# Webprogrammierung / Lösung / Eliza.js

Dies ist die **Musterlösung** zur Aufgabe „Eliza.js" aus der Vorlesung **Webprogrammierung** (Wirtschaftsinformatik, DHBW Karlsruhe), Kategorie *JavaScript*.

Der aus dem Selbststudium bekannte Eliza-Chatbot bekommt eine eigene Webanwendung und soll Nutzereingaben anhand von Schlüsselwörtern passende Antworten zuordnen.

Dieses Repository ist Teil der Quellcodes [dhbwka-wwi-webprog-quellcodes](https://github.com/DennisSchulmeister/dhbwka-wwi-webprog-quellcodes) zur Vorlesung Webprogrammierung.
